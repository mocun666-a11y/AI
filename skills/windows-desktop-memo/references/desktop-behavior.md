# 窗口、预览和数据

## Windows 穿透与后台运行

- 用 `GetAncestor(tk_window_id, GA_ROOT)` 获取顶层 HWND，声明指针宽度正确的 Win32 参数与返回值。
- 日常使用 `WS_EX_LAYERED`、`WS_EX_TRANSPARENT`、`WS_EX_NOACTIVATE`，作为工具窗口隐藏任务栏入口；编辑清除穿透及禁止激活标志。
- 透明度不等于点击穿透。用 `WindowFromPoint` 与 `GetAncestor` 验证同一点在编辑时命中组件、日常时命中下方窗口，另查滚轮和焦点。
- 托盘及热键线程通过队列交给 GUI 主线程，后台线程不要直接操作 Tk 控件。
- 全局快捷键可能冲突，保留桌面入口、托盘编辑和退出。单实例互斥锁与激活事件按应用标识命名。
- 右下角按工作区计算，避开任务栏。模板使用主显示器；其他显示器跟随需另行实现，不能声称已有。

## 实时预览与小窗口

- 原设置、候选设置、实际窗口几何分开，预览不逐帧写磁盘，保存失败不显示成功。
- 设置窗口保持不透明，预留最大预览宽度，不在拖动滑块时移动面板。
- 取消、关闭、Esc、外部快捷键和托盘模式切换均有一致的回退路径。
- 同时修改滑块下限、几何约束及读取设置的下限，避免重启后被旧限制弹回。
- 尺寸改变后直接按实际尺寸更新紧凑布局，不只依赖将来的 Configure 事件。源码事件循环正常不代表打包时也能及时刷新。
- 临时编辑尺寸不写回日常尺寸；长任务省略时仍保留原文，并提供完整查看入口。

## 壁纸

Tk Frame/Label 默认不透明，图片放在最底层可能完全被遮挡。模板日常视图用 Canvas 画背景、日期和任务，编辑用普通控件；日常展示，编辑交互。

- 处理 EXIF 方向、透明通道、损坏及过大图片，原图保持不变。
- 等比例裁切铺满，使用浅色遮罩或文字底板保证可读。保留 PhotoImage 引用，避免被回收后消失。
- 按图片来源与窗口尺寸缓存渲染，尺寸变化才更新，不在轮询中重复读取原图。
- 预览不导入应用数据目录；保存时保留副本并用内容摘要命名。验证移动原图后仍可重开。
- 验证取消、恢复纯色、读取失败与原壁纸恢复。此功能不隐含系统壁纸修改授权。

## 数据

按 ISO 日期分组，任务有唯一 ID。采用同目录临时文件、flush/fsync、replace 原子写入，并保留上一次有效备份。损坏主文件先另存，不能覆盖最后的可用备份。

验证中文、完成、删除撤销、重开、跨天和磁盘失败；区分内存状态与落盘状态。云同步、提醒、重复任务属于另外的明确需求。
