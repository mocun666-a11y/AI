# Windows 桌面备忘录

把用户要求落实为可直接运行的本地桌面工具，交付前验证 Windows 实际行为与已安装版本。沟通默认简体中文；尺寸、外观、数据范围以当前用户要求为准。

## 选择工作方式

- 修改现有程序：先定位运行文件、对应源码、用户数据位置及设置，在原工程内改动，不用模板覆盖用户工程。
- 新建同类程序：用 `scripts/scaffold_memo.py` 将 `assets/template/` 复制到新目录。模板包含 GUI、存储、壁纸处理、9 项测试及依赖清单。
- 只调整单项行为：只读有关参考，不强制执行完整制作流程。

模板只是起点：默认日期单行、可选周历，日常最小 220 × 220，编辑临时放大，支持本地图片背景。用户明确要求不同布局、尺寸或框架时修改实现并重新检查，不把默认值当作不可变约束。

## 行为约定

1. **点击穿透与按钮交互不能同时生效。** 日常点击和滚轮落到下面的窗口，不抢焦点；编辑状态不透明、可交互。保留托盘和桌面入口，即使快捷键占用也能编辑或退出。
2. **预览与保存分开。** 滑块、日历样式和壁纸立即反映在日常窗口；设置面板保持可操作，不随滑块移动。取消、关闭设置或切换模式恢复原配置；保存才持久化。
3. **小窗口不挤坏编辑界面。** 日常与临时编辑尺寸分开，收起恢复用户的小尺寸。省略显示的长任务保留全文，提示未显示数量，并能在编辑状态查看。
4. **只列当天计划，历史数据不丢失。** 按本机日期跨天。除非另有要求，不顺延昨天任务，也不把时间字段冒充响铃提醒。
5. **背景是备忘录背景。** 预览不修改原图，保存后保留应用私有副本；处理方向、透明图片及裁切，保证文字可读。不要顺带修改 Windows 桌面壁纸。

## 实施

涉及穿透、布局或背景，读 [references/desktop-behavior.md](references/desktop-behavior.md)。附带模板采用 Tkinter、Pillow、pystray 和 Win32；已有工程用其他框架时不要求迁移。

新建工程可执行：

```powershell
python <skill目录>/scripts/scaffold_memo.py --output <新工程目录> --app-id DailyNotesDemo --app-name 我的备忘录 --hotkey N
```

该脚本只生成源文件，不启动应用、安装依赖、创建快捷方式或修改启动项。应用标识用于数据目录、互斥锁、激活事件和注册表项；新应用用独立标识，更新原应用则保留原标识。

打包及更新时读 [references/build-and-update.md](references/build-and-update.md)。源码、打包和安装分别验证；功能检查用隔离的临时数据，不把示例任务写入用户计划。截图捕获失败须说明验证边界，不能称为目视验收成功。

只有当前项目或用户已授权才写入 Obsidian；更新同一工具笔记，保留用户补充，不把工具制作计入用户 Python 错题。GitHub 发布需要当前请求授权；具体内容检查见 [references/archive-and-publish.md](references/archive-and-publish.md)。
